**Applied Sensory Data Analytics & Computational Product Formulation**
 Executive Summary
This repository houses statistical sensory data pipelines, multivariate perceptual mappings, and product formulation case studies. By combining physical bench-formulation parameters (taste-masking, hydrocolloid interactions, volatile flavor retention) with open-source R sensometric packages (FactoMineR and SensoMineR), these projects convert quantitative sensory panel outputs into actionable product optimization decisions.
## Technical Core Competencies
 * **Sensometrics in R:** Principal Component Analysis (PCA), Multiple Factor Analysis (MFA), two-way mixed-effects ANOVA, and Just-About-Right (JAR) penalty analyses.
 * **Sensory Methodology:** Quantitative Descriptive Analysis (QDA), discrimination testing (triangle, duo-trio), panelist performance evaluation (paneliperf), and confidence ellipse plotting (panellipse).
 * **Commercial Formulation:** Bitterness suppression in plant proteins/nutraceuticals, ingredient cost optimization (COGS), and shelf-life sensory mapping.
## Portfolio Repository Structure
 * /scripts/01_pca_sensory_mapping.R - Automated R script executing PCA biplots and panel diagnostics on QDA datasets.
 * /case-studies/bitterness_suppression_study.md - Bench-to-data case study on plant-protein taste-masking and unit cost optimization.
 * /dashboards/ - Interactive Shiny dashboard templates for executive R&D reporting.
